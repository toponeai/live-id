# Live ID

أريد بناء تطبيق هاتف (موبايل) يعتمد على تقنية VoIP، يتيح للمستخدمين الاتصال ببعضهم البعض عبر الإنترنت، بحيث يظهر اسم المتصل على هيئة معرف مخصص بهذا الشكل: [نوع الخدمة].[رمز الدولة].[اسم المستخدم] (مثال: ID.Eg.TOPONE). أريد منك أن تضع لي خطة عمل شاملة، وتحدد التقنيات المطلوبة (مثل Flutter للواجهات، و Node.js أو Asterisk/FreeSWITCH للسيرفر)، وكتابة الأكواد الأساسية للبدء."  لكل مستخدم من كل دوله يمكنهم الحصول على نفس اسم المستخدم ولكن التغير في رمز البلاد ولا يمكن استخدام اثنان في بلاد واحده ولكل مستخدم اسم خاص به فقط . اجعل شكل البرنامج مثل برامج الهواتف معا اضافه كمكان البحث والاتصال و جهاز الاتصال و المحفوظات وغيرها . يمكنك اضافه اي مقترحات وافكار جديده ومميزه اضفها
